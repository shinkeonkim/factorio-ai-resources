# 업그레이드형 설계 원칙 (초반 → 중반 → 후반, 같은 구조)

[English](upgrade-in-place.en.md)

목표: 공장을 한 번 깔면 **배치를 바꾸지 않고** 업그레이드 플래너만으로 초반 → 중반 → 후반 설비로 올린다.
(예: 다이소 같은 몰, 과학팩 라인)

## 티어 정의

| 단계 | 벨트 | 조립기 | 인서터 | 전봇대 | 제련 |
|---|---|---|---|---|---|
| 초반 | 노랑 (15/s) | 조립기 1·2 | 일반 | 소형 | 돌 용광로 |
| 중반 | 빨강 (30/s) | 조립기 2 | 고속 | 중형 | 강철 용광로 |
| 후반 | 파랑/터보 (45·60/s) | 조립기 3 + 모듈 | 벌크(스택) | 중형 | 강철 → (별도) 전기/파운드리 |

## 1. 크기가 같은 것끼리만 바꾼다

| 계열 | 바뀌는 순서 | 주의 |
|---|---|---|
| 벨트·지하·스플리터 | 노랑 → 빨강 → 파랑 → 터보 | **지하 벨트 간격 ≤ 4칸**(노랑 한도)으로 설계해야 업그레이드 후에도 그대로 동작 |
| 조립기 | 1 → 2 → 3 (모두 3×3) | 조립기 1은 유체 입력·모듈이 없음 → 유체 레시피 칸은 처음부터 조립기 2 |
| 인서터 | 일반 → 고속 → 벌크(→ 스택, Space Age) | **롱암은 상위 티어가 없음**. 처리량이 중요한 자리에 롱암을 쓰지 않거나, 롱암 2개를 둘 자리를 처음부터 확보 |
| 전봇대 | 소형 → 중형 (1×1) | 배치를 **소형 기준**(5×5 공급, 7.5 연결)으로 잡으면 중형으로 바꿔도 문제 없음. 변전소(2×2)는 다른 배치 |
| 용광로 | 돌 → 강철 (2×2) | 전기 용광로(3×3)는 크기가 달라 같은 자리에서 못 바꿈 → 제련은 강철 용광로 열을 유지하고, 후반 증설은 전기 용광로/파운드리 별도 블럭으로 |

## 2. 비율은 티어가 바뀌어도 유지된다 — 단, 같이 올릴 것

한 블럭 안의 기계를 **모두 같은 티어로 함께** 올리면 기계 수 비율(예: 전선 3 : 회로 2)은 그대로이고 생산량만
같은 배수로 늘어납니다(조립기 1 → 2: ×1.5, 2 → 3: ×1.67). 일부만 올리면 그 부분만 빨라져 병목이 생깁니다.

## 3. 벨트와 인서터는 "최종 티어" 기준으로 여유를 둔다

- 입력 벨트는 후반 생산량을 감당할 줄 수로 처음부터 깝니다(초반엔 반쯤 비어 있어도 됨).
- 인서터 하나의 처리량(상자↔상자, 연구 보너스 없음): 일반 0.83/s, 고속 2.31/s, 벌크 2.31/s × 손 크기.
  기계 1대의 입출력 속도가 후반 티어에서 인서터 한도를 넘으면 인서터 칸을 2개 확보해 둡니다.

## 4. 모듈·비콘은 "자리만" 남겨 두거나 하지 않는다

비콘(3×3)을 나중에 넣으려면 배치가 달라집니다. 같은 구조를 유지하려면
(a) 비콘 없이 모듈만 넣는 것으로 후반을 마무리하거나, (b) 처음부터 비콘 줄 자리를 비워 둡니다.
이 저장소의 업그레이드형 블루프린트는 (a)를 기본으로 합니다.

## 5. 물은 어디서나 (waterfill)

waterfill 모드를 쓰므로 물 공급은 공장 옆에 물 타일 + 해양 펌프로 해결합니다.
블루프린트에는 물 입구에 `water` 표시 조합기만 두고, 긴 물 파이프는 깔지 않습니다.

## 체크리스트

- [ ] 지하 벨트 간격 ≤ 4칸
- [ ] 롱암이 처리량 병목이 아닌가
- [ ] 전봇대 간격이 소형 전봇대 기준으로 맞는가
- [ ] 유체 레시피 칸은 조립기 2 이상
- [ ] 용광로는 2×2 계열(돌·강철)로 통일
- [ ] 입력·출력 벨트 줄 수는 후반 티어 기준

## 쌓는 셀 (확장 규칙)

업그레이드와 함께 모든 공장은 **쌓는 셀**로 만듭니다(기준: 사용자 데모의 Nilaus 초록칩 모듈).

- 셀은 폭과 세로 주기가 고정이고, 입력 벨트는 양쪽 가장자리를 따라 북쪽으로, 제품은 가운데로 남쪽(버스 쪽)으로 흐릅니다.
- 모든 줄이 셀 아래쪽 가장자리로 들어와 위쪽 가장자리로 나가므로, 같은 셀을 한 주기 위에 붙이면 생산량이 그대로 늘어납니다. 입력 레인이 바닥나는 지점(각 README의 쌓기 표 "최대 셀 수")까지 늘릴 수 있습니다.
- 맨 아래에는 캡(시작 조각)을 한 번 놓습니다. 버스 분기를 받아 레인에 올립니다.
- 셀 파일은 셀 크기의 격자에 맞춰 붙으니 드래그로 여러 개를 한 번에 놓을 수 있습니다.
- 입력이 많은 제품(군사·보라·노랑 과학)은 중간재를 각자의 셀에서 만들어 받습니다.
- 구현: `lib/stack.py`(배치·캡·비율 분석), `lib/cells.py`(모든 셀 정의).
