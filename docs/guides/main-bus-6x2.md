# 메인버스 6+2 가이드

[English](main-bus-6x2.en.md)

이 저장소의 공장들은 **가로로 흐르는 메인버스**를 전제로 합니다. 자원은 6줄씩 묶고, 묶음 사이에 빈칸 2줄을 둡니다.

```
          ↑ 분기(공장으로)          ↑ 분기
..........^......................^..........   ← 빈칸 2줄: 분기 벨트·지하 벨트 입출구·전봇대 자리
..........^......................^..........
>>>>>>>>>U^u>>>>>>>>>>>>>>>>>>>>>^..........   ┐
>>>>>>>>>U^u>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>   │
>>>>>>>>>>^>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>   │ 6줄 묶음 (줄 0~5, 위에서부터)
>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>   │
>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>   │
>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>   ┘
............................................   ← 빈칸 2줄
............................................
>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>   6줄 묶음 ...
```

## 왜 6줄 + 2칸인가

- 6줄이면 철판 4 + 구리판 2처럼 한 묶음에 한 계열을 담기 좋고, 빈칸 2줄에 분기 벨트·지하 벨트 입출구·전봇대·램프를 둘 수 있습니다.
- 흔히 쓰는 "4줄 + 2칸" 버스보다 폭 대비 줄 수가 많습니다. 대신 한 묶음을 통째로 건너는 지하 벨트는 6칸이 필요해 **노랑 지하 벨트(최대 4칸)로는 못 건넙니다**. 그래서 이 키트는 묶음을 한 번에 건너지 않고, **분기 열에서 다른 줄들이 1~2칸만 잠수**하는 방식을 씁니다. 모든 티어에서 같은 배치로 동작합니다.

## 키트

| 조각 | 용도 |
|---|---|
| [기본 구간](../../blueprints/main-bus-6x2-segment/README.md) | 위 6묶음(고체 5 + 유체 1), 33칸. 줄마다 아이템 표시 조합기 |
| [분기 조각](../../blueprints/main-bus-6x2-tap/README.md) | 한 줄을 북쪽으로: 전부(full) / 반(half, 스플리터), 줄 0~5, 유체 줄 0~5 |
| [통과 조각](../../blueprints/main-bus-6x2-crossing/README.md) | 아래 묶음의 분기가 위 묶음을 세로로 지나갈 때 (벨트 / 유체) |

### 분기 만드는 순서

1. 공장을 놓을 열을 정하고, 해당 묶음에 분기 조각(줄 번호 맞춰서)을 **강제 건설(Shift+클릭)**로 덮어 놓습니다.
2. 그 묶음보다 위에 있는 묶음마다 같은 열에 통과 조각을 놓습니다.
3. 분기 벨트는 맨 위 묶음 위로 나와 공장으로 들어갑니다. 다음 분기는 최소 4~6칸 띄웁니다(인서터·전봇대·나중 확장 자리).

## 이 저장소의 버스 구성 (6묶음, 위 → 아래)

| 묶음 | 줄 0~5 | 비고 |
|---|---|---|
| 1 | 철판 ×6 | |
| 2 | 구리판 ×6 | |
| 3 | 녹색 회로 ×2, 적색 회로 ×2, 청색 회로 ×2 | |
| 4 | 강철 ×2, 플라스틱 ×2, 돌, 돌벽돌 | |
| 5 | 석탄, 황, 건전지, 엔진, 전기 엔진, 저밀도 구조물 | 후반 테크용 생산물 |
| 6 | **유체**: 석유가스, 경유, 중유, 윤활유, 황산, 물 | 지하 파이프 사슬. 물은 waterfill이면 생략 가능 |

- 전체 높이 46줄(6묶음 × 6줄 + 빈칸 2줄 × 5). 많이 쓰는 것을 위에 두어 분기가 건너는 묶음 수를 줄였습니다.
- 유체 묶음은 **맨 아래**입니다. 고체 분기는 위로만 나가므로 유체 줄을 건널 일이 없습니다.

### 유체 줄

- 각 유체 줄은 **지하 파이프(pipe-to-ground) 사슬**입니다(10칸마다 한 쌍). 지하 파이프는 지상 쪽 한 방향으로만 연결되므로, 6줄을 바로 붙여 놓아도 서로 섞이지 않습니다.
- **유체 분기**([분기 조각](../../blueprints/main-bus-6x2-tap/README.md)의 `fluid-line*`): 한 줄을 사슬 중간(쌍 사이 2~8칸 지점)에서 지상으로 올리고, 지하 파이프로 묶음 위 빈칸까지 올립니다.
- **위 묶음 건너기**([통과 조각](../../blueprints/main-bus-6x2-crossing/README.md)의 `fluid`): 아래 빈칸(첫 줄)에서 위 빈칸(마지막 줄)까지 지하 파이프 한 쌍. 묶음마다 하나씩 쌓으면 **빈칸 2줄이 위아래 쌍의 접점**이 됩니다.

```
  ...P...   ← 위 묶음의 아래 빈칸: 다음 통과 조각(남향)
  ...P...   ← 이 묶음의 위 빈칸: 통과 조각 상단(북향)
  >>>>>>>   ┐
  >>>>>>>   │ 6줄 묶음 (지하로 통과)
  >>>>>>>   ┘
  ...P...   ← 아래 빈칸: 통과 조각 하단(남향)
  ...P...   ← (아래 묶음의) 통과 조각 상단
```

- waterfill 모드를 쓰므로 **물은 필요한 공장 옆에 직접 만들어** 쓰는 것이 기본이고, 물 줄은 예비입니다.
- 분기 순서는 많이 쓰는 것부터 앞(서쪽)에 둡니다. 스플리터는 늘 반씩 나누므로 뒤쪽 공장은 앞쪽이 가득 찬 뒤에야 충분히 받습니다.

## 업그레이드

벨트·지하 벨트·스플리터만 바꾸면 됩니다(업그레이드 플래너). 줄 수와 위치는 그대로입니다. 줄당 용량: 노랑 900/분, 빨강 1,800, 파랑 2,700, 터보 3,600.
